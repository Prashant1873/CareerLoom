## 🚫 The Job Hunt Is Broken

If you have searched for a job recently, you already know the frustration:
- **The Ghost Job Trap**: Over 60% of postings on aggregator boards are already filled, expired, or reposted by automated bots.
- **The Keyword Lottery**: Having the exact right skills but being filtered out because your title didn't match an ATS keyword verbatim.
- **The Endless Redirect Loop**: Clicking "Apply", jumping through three ad-filled redirect portals, only to land on an email capture gate.
- **Zero Transparency**: Submitting resumes into black holes without knowing the interview timeline, real salary ranges, or actual team culture.

## ⚡ Enter CareerLoom

**CareerLoom** is built differently. It bypasses aggregators entirely by connecting directly to the internal Applicant Tracking Systems (**Greenhouse, Lever, Ashby, SmartRecruiters, and Workday**) of over **230+ top global employers and premier tech unicorns**.

## 🎯 How to Use CareerLoom

1. **Ask in Plain English**: Type your target role in the Omnibox (e.g., *"remote product manager"* or *"sde in bangalore"*).
2. **Filter by Freshness & Location**: Switch between Global, Remote, or Indian Tech Unicorns with one click.
3. **Inspect Real Intel**: Click any job card to read verified interview timelines, round breakdowns, and company background notes.
4. **Apply Directly**: Click **Apply Now ↗** to land straight on the company's official submission form. No accounts or registrations required.
5. **Bookmark**: Save jobs to your private local workspace to track your active applications.

## 🚢 Run Your Own CareerLoom

Want to host a private CareerLoom discovery portal for yourself, your university, or your community? The entire platform is containerized and ready for 1-command deployment.

### Option 1: Instant Local / VPS Deployment (Docker Compose)

```bash
# Clone the repository
git clone https://github.com/Prashant1873/CareerLoom.git
cd CareerLoom

# Launch both frontend and backend
docker compose up -d
```
Visit `http://localhost` to start discovering roles.

### Option 2: Production Kubernetes Deployment

CareerLoom includes a production-ready Kubernetes manifest (`deployment.yaml`) with unified Nginx ingress, auto-probes, persistent volume storage, and a daily ATS sync cron job:

```bash
# Apply complete multi-tier manifest
kubectl apply -f deployment.yaml
```

### Option 3: Free Cloud Deployment (Render / Hugging Face)

Use the included `render.yaml` blueprint for zero-cost deployment on Render, or deploy the backend container to Hugging Face Spaces with free frontend CDN hosting on Cloudflare Pages or Vercel.
