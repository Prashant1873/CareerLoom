# Plan 09-02: Multi-ATS Bulk Sync Runner & Live Database Population

## Goal
Implement a resilient, bounded-concurrency bulk sync pipeline (`backend/scripts/bulk_sync.py` and enhanced `backend/app/services/sync.py`) that concurrently queries all configured ATS endpoints across Greenhouse, Lever, Ashby, SmartRecruiters, and Workday, parses dates, deduplicates jobs, and commits thousands of live postings to `backend/data/jobs.db`.

## Requirements Covered
- **SCALE-02**: Multi-ATS connector validation and hardening for Greenhouse, Lever, Ashby, SmartRecruiters, and Workday with polite concurrency and rate-limit backoff.
- **SCALE-03**: High-throughput concurrent bulk ingestion runner with progress metrics, batch commits, and failure isolation.
- **SCALE-04**: SQLite cache populated with thousands of verified live job postings across diverse categories and countries.

## Tasks
1. **Harden Multi-ATS Connectors (`backend/app/scrapers/`)**:
   - Ensure timeout (10s) and polite backoff for 429 rate limits across all connectors.
   - Handle atypical ATS payloads gracefully without dropping whole company batches.
2. **Bulk Ingestion Script (`backend/scripts/bulk_sync.py`)**:
   - Provide a standalone CLI with `--concurrency 8 --limit N --domain Domain` flags.
   - Real-time terminal progress logger: `[Sync] 45/210: Databricks -> 84 jobs synced (Total: 3,420)`.
   - Batch database commits with atomic upserting.
3. **Execute Live Bulk Sync**:
   - Run `python backend/scripts/bulk_sync.py` to ingest real listings across top firms into SQLite.
   - Verify thousands of jobs populated in `backend/data/jobs.db`.

## Verification Checkpoint
- Ingestion executes without unhandled exceptions.
- Database contains at least 3,000+ active job records across 30+ companies.
