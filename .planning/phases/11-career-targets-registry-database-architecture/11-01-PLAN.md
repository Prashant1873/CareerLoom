<task type="auto" id="11-01-02">
<title>Extend Database Schema & Stale Job Reconciler in database.py</title>
<instruction>
Update `backend/app/db/database.py`:
1. In `init_db()`:
   - Create table `career_targets` matching locked decision `D-01`.
   - Create composite indexes `idx_targets_category`, `idx_targets_status`, `idx_targets_last_scraped`.
   - Implement `_ensure_column(db, 'jobs', 'is_active', 'INTEGER DEFAULT 1')` and `_ensure_column(db, 'jobs', 'last_seen_at', 'TEXT')` to safely alter existing SQLite table without errors.
   - Create index `idx_jobs_is_active` on `jobs(is_active)`.
2. Update `get_jobs()` / query builder:
   - Ensure default query includes `WHERE is_active = 1` (or allows `include_inactive: bool = False`).
   - Maintain sub-50ms query latency.
3. Add target DB operations:
   - `upsert_target(target: CareerTarget) -> None`
   - `upsert_targets(targets: List[CareerTarget]) -> int`
   - `get_targets(params: CareerTargetFilterParams) -> Tuple[List[CareerTarget], int]`
   - `get_target_by_slug(slug: str) -> Optional[CareerTarget]`
   - `get_target_stats() -> CareerTargetStats`
4. Add stale job reconciler:
   - `reconcile_target_jobs(company: str, live_job_ids: List[str], sync_timestamp: str) -> Dict[str, int]`
   - Updates `last_seen_at = sync_timestamp` and `is_active = 1` for `id IN (live_job_ids)`.
   - Sets `is_active = 0` for `company = ? AND id NOT IN (live_job_ids)`.
   - Updates `career_targets` table: sets `job_count = len(live_job_ids)`, `last_scraped_at = sync_timestamp`, and `last_status = 'ok'`.
</instruction>
