<task type="auto" id="11-02-01">
<title>Build Catalog Seed Migrator (seed_targets.py)</title>
<instruction>
Create `backend/scripts/seed_targets.py`:
1. Consolidate companies from:
   - `backend/scripts/add_indian_companies.py`: 51+ curated Indian unicorns and startups (Paytm, Swiggy, Meesho, CRED, Groww, InMobi, Glance, Sarvam AI, Atlan, Slice, Navi, Druva, HighRadius, Zenoti, Mindtickle, SigNoz, Zeta, etc.).
   - `backend/app/data/companies.json`: 237 global and Indian employers.
2. Enrich each target with:
   - `slug`: unique URL-safe identifier (e.g. `swiggy`, `cred`, `mckinsey-india`).
   - `career_url`: official career landing page URL (fallback or inferred from ATS feed).
   - `feed_url`: direct JSON/API endpoint if applicable.
   - `category_tier`: 'startup', 'unicorn', 'enterprise', or 'consulting'.
   - `domain`: Industry sector (Fintech, AI, SaaS, Quick Commerce, Consulting, etc.).
   - `role_focus`: list of tags (e.g. `['product', 'tech']` for Swiggy; `['strategy', 'consulting']` for McKinsey/BCG/Bain; `['product', 'strategy', 'tech', 'founders_office']` for unicorns).
   - `status`: 'active'.
3. Implement `seed_career_targets(force: bool = False) -> int`:
   - Checks existing count in `career_targets`.
   - If `force=False` and count > 0, skips seeding to remain idempotent.
   - If count == 0 or `force=True`, upserts all target records using `upsert_targets()`.
4. Support CLI flags: `python -m backend.scripts.seed_targets [--force]`.
</instruction>
<verification>
`python backend/scripts/seed_targets.py` runs and reports total seeded targets (200+).
</verification>
</task>

<task type="auto" id="11-02-02">
<title>Implement Target Management REST APIs (backend/app/api/targets.py)</title>
<instruction>
Create `backend/app/api/targets.py` with FastAPI router:
1. `GET /api/targets`:
   - Query params: `tier: Optional[str]`, `domain: Optional[str]`, `role_tag: Optional[str]`, `status: Optional[str]`, `search: Optional[str]`, `limit: int = 50`, `offset: int = 0`.
   - Returns JSON: `{"items": [CareerTarget], "total": int, "limit": int, "offset": int}`.
2. `GET /api/targets/stats`:
   - Returns JSON with `CareerTargetStats`: total targets, active count, by-tier breakdown, total live jobs.
3. `GET /api/targets/{slug}`:
   - Returns single `CareerTarget` or 404 if not found.
4. `POST /api/targets/{slug}/sync`:
   - Looks up target by slug.
   - Triggers `JobSyncService.sync_company_target(target)`.
   - Reconciles jobs and updates target metadata.
   - Returns `{"slug": slug, "status": "ok", "jobs_synced": int, "live_jobs": int}`.
5. In `backend/app/main.py`:
   - Include router: `app.include_router(targets.router, prefix="/api/targets", tags=["targets"])`.
   - In FastAPI lifespan startup handler, invoke `seed_career_targets(force=False)` to auto-seed if empty.
</instruction>

Start backend or test import; verify routes are registered in OpenAPI schema.
</verification>
</task>
