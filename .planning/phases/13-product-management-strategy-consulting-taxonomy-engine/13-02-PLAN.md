<instruction>

   - If `params.track`:
     - Match: `LOWER(track) = LOWER(?)`
     - Parameter value: `params.track.strip()`
2. Support `params.cluster`:
   - If `params.cluster`:
     - Use `get_categories_in_cluster(params.cluster)` from `taxonomy.py`.
     - Match: `LOWER(category) IN (?, ?, ...)`
3. Handle Broad `params.category`:
   - If `params.category`:
     - Use `resolve_category_or_cluster(params.category)` from `taxonomy.py`.
     - If resolved to multiple categories (e.g. "product" -> `product`, `technical_product`, `product_ops`), generate `LOWER(category) IN (?, ?, ...)`.
     - If resolved to single category, use `LOWER(category) = LOWER(?)`.
4. (D-09) Hybrid Synonym Fallback:
   - If `params.track` is provided and the primary query returns fewer than 5 results:
     - Retrieve synonyms for the track from `CATEGORIES_TAXONOMY`.
     - Re-execute query replacing strict `track = ?` with `(LOWER(track) = LOWER(?) OR title LIKE ? OR ...)` to prevent zero-result drop-offs on unstandardized titles.
</instruction>
