  <files>backend/app/api/nlp.py, backend/app/main.py</files>
  <action>
    Create backend/app/api/nlp.py:
    - `POST /api/nlp/parse`: Ingests `{"prompt": str}` and returns structured parameters `{ "search_terms", "category", "seniority", "country", "is_remote", "domain", "posted_within_days" }`.
    - `POST /api/nlp/search`: Ingests `{"prompt": str, "limit": Optional[int], "offset": Optional[int]}`:
      1. Parses prompt via `parse_natural_language_query()`.
      2. If category phrase matched via taxonomy, merges taxonomy hints.
      3. Constructs `JobFilterParams` and calls `query_jobs()`.
      4. Returns `{ "parsed_parameters": dict, "total": int, "jobs": List[JobItem] }`.

    Register `nlp.router` in backend/app/main.py under prefix `/api`.
  </action>
