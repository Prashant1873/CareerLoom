    Create backend/app/services/taxonomy.py:
    - Defines canonical categories with metadata:
      - `id`: slug (e.g. `product`, `software_engineering`, `data_ai`, `design`, `finance_quant`, `consulting_strategy`, `sales_gtm`)
      - `label`: display title (e.g. "Product Management", "Software Engineering", "AI & Data Science")
      - `curated_tracks`: list of quick discovery queries (e.g., "Product Entry Level", "Associate Product Manager", "Junior ML Engineer", "Founding Engineer Remote")
      - `synonyms`: extensive list of matching title substrings (e.g., for `product`: ["product manager", "pm", "apm", "technical product manager", "product owner", "product lead"])

    - `match_category_phrase(phrase: str) -> Optional[dict]`: maps freeform role track phrases to canonical category + seniority + keywords.
  </action>
