# Plan 03-01: Frontend Scaffolding & Design System

## Goal
Scaffold a modern, lightweight Vite + React 19 + TypeScript application in `frontend/` with curated design tokens, CSS variables, typography, and anti-slop aesthetic foundations adhering to `frontend-skill`.

## Context & Requirements
- **Requirements**: UI-01
- **Design Read**: Operate / Discovery Portal for ambitious candidates searching top global tech, finance, consulting, and AI firms. Modern precision craftsmanship (charcoal/obsidian background, crisp high-contrast typography, emerald/cyan accents, optical balance).
- **Dials**: Variance: 6 | Motion: 7 | Density: 7
- **Stack**: React 19 + Vite 6 + TypeScript + Lucide React + Vanilla CSS design tokens (no bulky Tailwind dependencies).

## Tasks

### Task 1: Initialize Vite React TypeScript Project
Initialize the Vite project inside `frontend/` with `npm create vite@latest frontend -- --template react-ts`.
Install runtime dependencies: `lucide-react`.

### Task 2: Implement Design Token System & Base CSS (`frontend/src/index.css`)
- Configure dark/light mode palette with CSS custom properties:
  - Surfaces: `--bg-base`, `--bg-surface`, `--bg-elevated`, `--bg-subtle`, `--border-subtle`, `--border-hover`
  - Text: `--text-primary`, `--text-secondary`, `--text-muted`
  - Accents: `--accent-primary` (emerald/mint for freshness), `--accent-subtle`, `--accent-glow`
  - Radii: `--radius-sm: 6px`, `--radius-md: 10px`, `--radius-lg: 14px`, `--radius-full: 9999px`
  - Shadows: subtle ambient elevation without fuzzy slop
- Load modern typography (Inter / Outfit / JetBrains Mono via Google Fonts or system stacks).
- Reset and base accessibility styles: focus rings (`:focus-visible`), WCAG 2.2 AA compliant contrast (4.5:1 min).

### Task 3: API Client & TypeScript Types (`frontend/src/types/job.ts`, `frontend/src/services/api.ts`)
- Model contracts aligned with backend `JobItem`, `ParsedQuery`, `Category`, `DiscoveryTrack`.
- Typed API client with fetch methods for:
  - `fetchCategories()`
  - `fetchDiscoveryTracks()`
  - `searchJobs(params)`
  - `nlpSearch(prompt, filterOverrides)`
  - `getJobStats()` / `healthCheck()`

## Verification
- `npm run build` in `frontend/` succeeds with 0 type errors.
- Dev server runs cleanly.
