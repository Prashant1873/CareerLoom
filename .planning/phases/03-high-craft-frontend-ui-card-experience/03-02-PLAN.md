# Plan 03-02: Search Bar, Category Quick-Pills & Faceted Sidebar

## Goal
Build the conversational natural language search bar with instant query feedback, horizontal scrolling category & track quick-pills, and an accessible faceted filter sidebar.

## Context & Requirements
- **Requirements**: UI-01, NLP-01, NLP-04, FILTER-01, FILTER-02, FILTER-03, FILTER-04, FILTER-05
- **Design Principles**:
  - Conversational input with subtle active glow, clear icon, keyboard shortcut (`/` to focus).
  - Quick-pill discovery carousel for broad categories (e.g. "Product Entry Level", "Machine Learning New Grad", "Quant Dev").
  - Faceted filters: Country / Region (US, UK, Europe, India, Global), Remote Work (All, Remote, Hybrid, Onsite), Industry Domain (Tech, Fintech, Consulting, AI), Seniority, and Freshness (Past 24h, 7d, 14d, 30d, Any).
  - Active filter chips with one-click clear.

## Tasks

### Task 1: Conversational Search Bar (`frontend/src/components/SearchBar.tsx`)
- Omnibox input with search icon, clear button, and NLP indicator badge showing model interpretation.
- Keyboard navigation: `/` to focus, `Escape` to blur, `Enter` to search.
- Debounced search & instant query parsing feedback.

### Task 2: Category & Track Quick-Pills (`frontend/src/components/CategoryPills.tsx`)
- Fetches and displays canonical categories and top discovery tracks.
- Click-to-apply with active state styling.
- Smooth horizontal scroll container with gradient edge masks.

### Task 3: Faceted Filter Controls (`frontend/src/components/FilterSidebar.tsx`)
- Collapsible or sticky sidebar with accordion groups:
  - Freshness (segmented button / radio: 24h, 7d, 14d, 30d, All)
  - Remote (pill toggles: Remote Only, Hybrid, Onsite)
  - Region / Country (dropdown or quick chips)
  - Domain (chips: Tech, AI, Fintech, Consulting, Quant)
  - Sort By (Newest First, Company, Title)
- "Clear all filters" action and active filter counter.

## Verification
- Search query and filters update state and trigger live backend searches.
- URL state or query parameter sync for shareability.
