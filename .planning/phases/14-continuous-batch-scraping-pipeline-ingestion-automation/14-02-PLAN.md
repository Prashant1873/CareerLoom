<objective>
Implement the continuous background scheduling service (`BackgroundBatchScheduler`), REST API trigger and status endpoints (`POST /api/targets/sync`, `GET /api/targets/sync/status`, `POST /api/targets/purge-stale`), and FastAPI lifespan automation with graceful cancellation.

Requirements covered: BATCH-03.
Security Threats mitigated: T-14-01 (Overlapping Sync Starvation).
Output: `backend/app/services/scheduler.py`, upgraded `backend/app/api/targets.py`, upgraded `backend/app/main.py`, and test suite `tests/test_batch_api_scheduler.py`.
</objective>

<threat_model>
ASVS Level: 1
Threats:
- T-14-01 (HIGH): Overlapping Sync Starvation — Multiple concurrent `POST /api/targets/sync` calls spawn uncontrolled batch processes, causing DB lock contention and memory exhaustion.
  Mitigation: Mutex lock `_is_running` in `BackgroundBatchScheduler`. Any concurrent call while `_is_running=True` returns HTTP 409 Conflict.
</threat_model>

  <action>
    Create `backend/app/services/scheduler.py` implementing `BackgroundBatchScheduler`:
    1. Define `class BackgroundBatchScheduler`:
       - Attributes:
         - `_is_running: bool = False` (concurrency mutex - T-14-01)
         - `_status: str = "idle"` ("idle", "running", "completed", "error")
         - `_current_progress: Dict[str, Any]` (stores processed, total, current_target, live_jobs, archived_jobs)
         - `_last_run_at: Optional[str] = None`
         - `_next_run_at: Optional[str] = None`
         - `_last_run_stats: Optional[Dict[str, Any]] = None`
         - `_task: Optional[asyncio.Task] = None`
         - `_interval_seconds: float` (parsed from env var `SYNC_INTERVAL_HOURS` default 12, or `SYNC_INTERVAL_SECONDS`; if 0, periodic loop is disabled)
       - Method `start(self) -> None`:
         - If `_interval_seconds > 0` and `_task is None`: creates `asyncio.create_task(self._periodic_worker())`.
       - Method `async def stop(self) -> None`:
         - Cancels `_task` if running and waits for graceful cancellation.
       - Method `async def trigger_now(self, tier: Optional[str] = None, domain: Optional[str] = None, limit: Optional[int] = None, concurrency: int = 15) -> bool`:
         - If `self._is_running`: returns False (signals conflict - T-14-01).
         - Sets `self._is_running = True` and launches `self._execute_batch(tier, domain, limit, concurrency)` as an asynchronous task.
         - Returns True.
       - Method `async def _execute_batch(self, ...)`:
         - Updates `_status = "running"`, resets `_current_progress`.
         - Instantiates `BatchScrapeRunner(concurrency=concurrency)`.
         - Calls `runner.run(..., progress_callback=self._on_progress)`.
         - On completion: records `_last_run_at`, stores `_last_run_stats`, updates `_status = "completed"`.
         - On error: logs exception, updates `_status = "error"`.
         - In finally block: sets `self._is_running = False`.
       - Method `get_status(self) -> Dict[str, Any]`:
         - Returns dictionary with `status`, `is_running`, `current_progress`, `last_run_at`, `next_run_at`, and `last_run_stats`.
    2. Instantiate module-level singleton `batch_scheduler = BackgroundBatchScheduler()`.
  </action>

    - `backend/app/services/scheduler.py` defines `batch_scheduler` singleton

    - `get_status` returns dictionary containing `status` and `is_running`
