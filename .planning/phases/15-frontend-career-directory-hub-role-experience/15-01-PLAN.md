<objective>
Build the Career Targets TypeScript contracts, API client service, and the standalone `CareerDirectoryModal` component with responsive card grid, faceted search, tier filters, ATS provider badges, live job counts, and 15-UI-SPEC state coverage.

Requirements covered: V5-UI-01.
Design Contract: `15-UI-SPEC.md` (Obsidian Dark palette, 4px grid spacing, WCAG 2.2 AA contrast, 8-card shimmer skeleton loading, designated empty state).
Output: `frontend/src/types/job.ts`, `frontend/src/services/api.ts`, `frontend/src/components/CareerDirectoryModal.tsx`, and `frontend/src/components/CareerDirectoryModal.css`.
</objective>

<threat_model>
ASVS Level: 1
Threats:
- T-15-01 (MEDIUM): Reverse Tabnabbing & Malicious External Redirects — Opening employer career portal URLs without security attributes allows target pages to tamper with window.opener.
  Mitigation: Enforce `target="_blank" rel="noopener noreferrer"` on all external links in `CareerDirectoryModal`.
- T-15-02 (LOW): UI Freeze from Large Catalog Render — Rendering hundreds of company cards at once causes DOM layout thrashing.
  Mitigation: Implement pagination (`limit=60` with infinite/lazy pagination or offset paging) and lightweight semantic card markup.
</threat_model>
