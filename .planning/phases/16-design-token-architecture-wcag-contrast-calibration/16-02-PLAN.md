<task id="16-02-02">
  <read_first>
    - FRONTEND_PLAN.md
  </read_first>
  <action>
    Create automated WCAG 2.2 contrast validation script `scripts/verify_contrast.py`:
    1. Parse sRGB luminance formula: $L = 0.2126 R + 0.7152 G + 0.0722 B$.
    2. Compute contrast ratio: $(L_1 + 0.05) / (L_2 + 0.05)$.
    3. Evaluate all pairs for dark mode:
       - `--text-primary` on `--bg-base` (expected > 14:1)
       - `--text-secondary` on `--bg-surface` (expected > 7:1)
       - `--text-muted` on `--bg-surface` (expected >= 4.5:1)
       - `--accent-primary` on `--bg-base` (expected >= 3:1)
    4. Evaluate all pairs for light mode:
       - `--text-primary` on `--bg-surface` (expected > 14:1)
       - `--text-secondary` on `--bg-surface` (expected > 7:1)
       - `--text-muted` on `--bg-surface` (expected >= 4.5:1)
       - `--accent-primary` on `--bg-surface` (expected >= 4.5:1)
       - Badge text colors against white and badge pastel backgrounds (expected >= 4.5:1).
    5. Output formatted verification table and exit with status 0 if all pass.
  </action>
  <verification>
    Execute `python scripts/verify_contrast.py` and confirm 100% pass rate.
  </verification>
</task>
