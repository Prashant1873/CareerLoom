# Plan 03-03: Job Card Grid, Posting Date Highlight, Direct Apply & Bookmarks

## Goal
Build the responsive job card grid presenting rich, high-craft job cards with prominent posting dates (exact + relative), verified direct career site apply CTA, bookmarking persisted in `localStorage`, and interactive drawer for job detail view.

## Context & Requirements
- **Requirements**: UI-02, UI-03, UI-04, UI-05
- **Design Specifications**:
  - High-craft card design: Employer name, job title, domain badge, location & remote pill, seniority badge.
  - **Date Posted Prominence**: Bold, high-visibility badge with relative time ("2 days ago", "Today", "Yesterday") alongside exact formatted date tooltip or subtitle (`Oct 1, 2026`).
  - **Direct Apply CTA**: Distinctive button opening official ATS career portal (`apply_url`) in new tab with verified security attributes (`rel="noopener noreferrer"`).
  - **Bookmarking**: Star / bookmark icon with optimistic update, persisted in `localStorage` with a dedicated "Saved Jobs" filter/tab.
  - **Empty & Loading States**: Elegant animated skeletons during fetch; helpful empty state with suggestion pills when no jobs match.

## Tasks

### Task 1: Job Card Component (`frontend/src/components/JobCard.tsx`)
- Card layout with title, company, domain badge, location tag, and remote badge.
- Dual date display: prominent relative time badge (color-coded for freshness: green for <24h, cyan for <7d) + exact date string.
- Action row: "Apply on Company Site" CTA button with external link icon + Bookmark toggle button.
- Click card to open full detail drawer.

### Task 2: Job Card Grid & Results Header (`frontend/src/components/JobGrid.tsx`)
- Responsive grid (1 col mobile, 2 col tablet/desktop, 3 col wide).
- Results bar: Showing total matches found, active sorting selector, and toggle for "Saved Jobs (N)".
- Loading skeleton states with shimmer effect adhering to Doherty 400ms threshold.
- Zero-results empty state with quick reset recommendations.

### Task 3: Job Detail Drawer & Local Storage Bookmarks (`frontend/src/components/JobDetailModal.tsx`, `frontend/src/hooks/useBookmarks.ts`)
- Slide-over or modal with full description summary, requirements tags, company info, and primary apply button.
- Custom hook `useBookmarks` managing saved job IDs in `localStorage`.

### Task 4: Complete App Assembly & E2E Validation (`frontend/src/App.tsx`)
- Unify Header, SearchBar, CategoryPills, FilterSidebar, JobGrid, and JobDetailModal.
- Verify end-to-end against live backend running with real jobs.

## Verification
- Cards render real jobs fetched from FastAPI backend.
- Date posted displays correctly for all listings.
- Apply button opens verified ATS links.
- Bookmark persists across browser reloads.
- Responsive across desktop and mobile screen sizes.
