# Plan 07-01: Master Job Stream & Keyboard Navigation Flow

## Goal
Build the central master job stream (`MasterJobStream.tsx`) with a sticky omnibox search bar (`/` key shortcut), active filter chips, sort controls, and keyboard-first cursor navigation hook (`useKeyboardNav.ts`) for seamless `J`/`K`/`S`/`Enter` control.

## Context & Requirements
- **Requirements**: V2-STREAM-01, V2-KEYBOARD-01, V2-MOTION-01
- **Adheres to**: `frontend-skill` (high-density list items, glowing emerald active indicator, instant 0-latency pointer response, Apple HIG spring feedback).

## Tasks

### Task 1: Keyboard Navigation Hook (`frontend/src/hooks/useKeyboardNav.ts`)
- Listen to global key events (when not typing in search input):
  - `j` or `ArrowDown`: Move selection to next job in stream.
  - `k` or `ArrowUp`: Move selection to previous job in stream.
  - `s`: Toggle bookmark on selected job.
  - `Enter`: Open official ATS application URL in new tab.
  - `/`: Focus search input.
  - `Escape`: Clear search or blur input.

### Task 2: Master Job Stream Component (`frontend/src/components/MasterJobStream.tsx`)
- Sticky search header:
  - Omnibox search input with `/` shortcut badge and real-time NLP status pill.
  - Active filter chips row with clear buttons (`x`).
  - Stream controls: result count, sort dropdown (date, relevance, company), view density toggle.
- Stream list:
  - Renders compact high-density job cards.
  - Active/selected job card highlighted with obsidian hairline border and emerald glow accent.
  - Prominent dual date posted pill (relative + exact date).
  - Quick action buttons (bookmark, direct apply CTA).
  - Skeleton loaders and zero-state screen.

### Task 3: Integration & Verification
- Mount `MasterJobStream` in Column 2 of `App.tsx`.
- Connect keyboard hook and test with `npm run build`.
