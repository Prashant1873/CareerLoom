# Plan 04-01: BeautifulSoup4 Custom Portal Crawler Framework

## Goal
Build a robust, rate-limited HTML crawler and cleaner in `backend/app/scrapers/custom_crawler.py` using `httpx` and `BeautifulSoup4` that extracts job listings from custom corporate career pages lacking standard ATS JSON endpoints.

## Context & Requirements
- **Requirements**: SCRAPER-01
- **Approach**:
  - Respect rate limits and anti-bot measures using modern browser headers (`User-Agent`, `Accept`, `Sec-Fetch-*`), random jitter delays, and automatic retry on 429/503.
  - HTML pre-processor that strips redundant boilerplate (`<script>`, `<style>`, `<nav>`, `<footer>`, header tags, SVGs) to reduce payload size by 90% before parsing.
  - Heuristic DOM extractor that scans for common job list patterns (elements containing job titles, location, and apply links).

## Tasks

### Task 1: Browser-Mimicking Async HTTP Client (`backend/app/scrapers/custom_crawler.py`)
- Configurable headers with rotating realistic User-Agents.
- Semaphore-based rate limiting per domain.
- Timeout resilience (10s default) with clean error logging.

### Task 2: HTML Content Cleaner & Semantic Block Extractor
- Strips script, style, svg, path, nav, footer, iframe, noscript.
- Extracts clean candidate blocks: `<a>` tags with career/job URLs, `<li>` or `<div>` cards containing title and location text.
- Extracts dates using `backend.app.utils.date_parser.parse_date_posted`.

### Task 3: Unit Tests (`tests/test_custom_crawler.py`)
- Test HTML cleaning and card block extraction on sample enterprise career pages.
- Test date and URL normalization.
