# Plan 04-02: LLM-Assisted Scraper Pipeline & Custom Portal Sync

## Goal
Build the LLM-driven graph extraction engine in `backend/app/scrapers/llm_scraper.py` that takes unstructured career portal HTML content, uses our multi-provider LLM adapter (or local heuristic extraction) to structure jobs into `JobItem` records, and integrates custom portals into `backend/app/services/sync.py`.

## Context & Requirements
- **Requirements**: SCRAPER-01
- **Design**:
  - `LLMPortalExtractor`: Takes cleaned HTML text blocks and prompts the LLM (Groq / Gemini / heuristic fallback) to return structured JSON arrays of job objects (title, location, is_remote, apply_url, date_posted, description_summary).
  - Seed custom portal catalog in `backend/app/data/custom_portals.json` for major firms with custom portals (e.g. McKinsey, Apple, Bloomberg, Goldman Sachs).
  - Integrate with `sync.py` and `database.py` so custom crawler jobs are indexed alongside Greenhouse/Lever/Ashby jobs in SQLite.

## Tasks

### Task 1: LLM-Assisted Portal Extractor (`backend/app/scrapers/llm_scraper.py`)
- Takes raw cleaned text from `custom_crawler.py`.
- Formulates extraction prompt requesting strict JSON schema matching `JobItem`.
- Parses response into `List[JobItem]` with UTC date parsing and deterministic SHA-256 ID generation.

### Task 2: Custom Enterprise Portals Catalog (`backend/app/data/custom_portals.json`)
- Seed list of major enterprise firms that do not use Greenhouse/Lever/Ashby.
- Portal URLs, target domain, and extraction hints.

### Task 3: Ingestion Pipeline Integration (`backend/app/services/sync.py` & `backend/app/api/jobs.py`)
- Add `sync_custom_portals()` to sync service.
- Add endpoint `POST /api/jobs/sync/custom` or trigger during company live sync.
- Verification tests in `tests/test_custom_crawler.py`.

## Verification
- Unit and integration tests passing.
- Custom portal extraction returns valid `JobItem` models saved in SQLite.
