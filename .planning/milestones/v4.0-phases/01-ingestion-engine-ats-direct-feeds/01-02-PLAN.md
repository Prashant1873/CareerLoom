  <name>Task 1: Build Universal Publication Date Normalizer</name>
  <files>backend/app/utils/date_parser.py</files>
  <action>
    Create backend/app/utils/date_parser.py:
    - `parse_posting_date(raw_date: Union[str, int, float, None]) -> datetime`:
      - Handles ISO 8601 strings (e.g., "2026-03-28T12:00:00Z").
      - Handles Unix timestamps in seconds or milliseconds (Lever uses epoch milliseconds, e.g. 1711627200000).
      - Handles relative strings ("2 hours ago", "3 days ago", "just posted").
      - Returns a timezone-aware UTC datetime.
      - Fallback: returns current UTC datetime if null/unparseable, with a logged warning.
  </action>
  <verify>python -c "from backend.app.utils.date_parser import parse_posting_date; assert parse_posting_date('2026-03-25T10:00:00Z').year == 2026; print('Date parser verified')"</verify>

    - Parses epoch millisecond timestamps

  </acceptance_criteria>
  <done>Date normalizer handles multiple ATS timestamp formats reliably</done>
</task>

      - Returns List[JobItem].
  </action>
