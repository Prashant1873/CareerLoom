  <name>Task 2: Build Concurrent Ingestion Sync Service</name>
  <files>backend/app/services/sync.py</files>
  <action>
    Create backend/app/services/sync.py:
    - `JobSyncService`:
      - Manages registry of connectors (Greenhouse, Lever, Ashby).
      - `sync_company(company_info: dict) -> int`: fetches jobs for one company and upserts to DB.
      - `sync_all(concurrency: int = 5) -> dict`: uses `asyncio.gather` with an `asyncio.Semaphore(5)` to avoid hammering network or local connection pools.
      - Returns summary: `{"total_synced": int, "companies_processed": int, "errors": List[str]}`.
      - Graceful error isolation: if one company board fails or is down, it logs the warning and continues syncing the rest.
  </action>
  <verify>python -c "import asyncio; from backend.app.services.sync import JobSyncService; s = JobSyncService(); res = asyncio.run(s.sync_company({'name': 'Figma', 'slug': 'figma', 'ats_type': 'greenhouse', 'domain': 'Design/Tech'})); print(f'Sync test synced {res} jobs')"</verify>
  <acceptance_criteria>

    Create backend/app/api/jobs.py router:
